Metis AI deployment notes
=========================

Keep deployment-specific URLs, credentials, host paths, and tokens outside
the repository. Use the private deployment environment to provide:

  CURSOR_API_KEY
  CHAT_PASSWORD
  MCP_BEARER_TOKEN
  AI_CHAT_ROOT
  AI_CHAT_MCP_STATE_DIR
  AGENT_CWD

Build and run the application with the package manager configured for the
deployment. The native installer generates
`deploy/metis-ai-worker.service` for the target user, paths, and environment
file; do not copy the template unchanged.

One-line installers
-------------------

Interactive Linux:

  bash -c "$(curl -fsSL https://metis-ai.f1shy312.com/install/linux)"

Interactive macOS:

  bash -c "$(curl -fsSL https://metis-ai.f1shy312.com/install/macos)"

Interactive Windows PowerShell:

  irm https://metis-ai.f1shy312.com/install/windows | iex

For AI and CI usage, always pass `--non-interactive` (or `-NonInteractive`
on PowerShell) and provide all required values. See README.md for the complete
argument reference and machine-readable `--dry-run --json` mode.

MCP gateway
-----------

The gateway module is part of the application at:

  packages/mcp-gateway/

By default it listens on localhost. Set `MCP_PORT`, `MCP_PUBLIC_URL`, and
`MCP_BEARER_TOKEN` only in the private environment. Do not expose the gateway
to the public internet without authentication and a trusted network boundary.

Security checklist
------------------

- Never commit `.env`, tokens, chat passwords, databases, logs, or `data/`.
- Rotate any credential that was ever present in a repository or log.
- Review shell, filesystem, Docker, systemd, and remote desktop tools before
  enabling them in a public deployment.
- Optional and remote MCP servers are disabled by default.
